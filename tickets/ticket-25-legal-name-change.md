# Ticket 25 — Account Update: Legal Name Change

> Self-directed simulator practice. Fictional data. Not paid work.

| Field | Detail |
|---|---|
| Priority | Medium |
| Type | Service Request — account update |
| Category | Identity / Access |
| Request | Update display name and primary email following a legal name change; retain the old email address as a working alias. |

---

## 1. Request detail

Employee legally changed her last name and requested her account be updated to
reflect it, with HR approval already recorded. Requested changes:

- Display name updated to the new legal name.
- New primary email address assigned.
- Previous email address retained as a working alias so existing correspondence
  is not lost.

## 2. Verification before action

Identity was verified before making changes, notwithstanding HR's prior approval —
confirming the request applied to the correct account rather than acting on
approval alone.

## 3. Action taken

- Updated the display name on the account.
- Set the new address as the primary email.
- Retained the previous address as an alias so mail sent to either address is
  delivered to the same mailbox.

## 4. Verification

- Confirmed the account still logs in normally after the change.
- Confirmed mail delivery to both the new primary address and the retained alias.

## 5. Status

**Resolved (request fulfilled)** — name and email updated; login and mail delivery
to both addresses confirmed.

---

## Lessons learned

1. **Verify identity even when a request arrives pre-approved.** HR approval
   confirms the request is legitimate; it does not confirm the technician is
   changing the correct account.

2. **Retaining the old address as an alias avoids losing in-flight
   correspondence.** A name/email change should not break delivery of messages
   already sent to, or expected at, the previous address.

3. **Confirm the account functions after the change, not just that settings
   saved.** Verifying login and mail delivery to both addresses closes the loop on
   whether the update actually works end to end.
